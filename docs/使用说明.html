抖音文案提取工具 · 使用说明

版本 0.1.1  ·  适用于 Windows 10 / 11（64 位） ·  解压即用，无需安装

三步上手

  1. 把压缩包解压到任意目录，比如 D:\抖音工具（路径别太深）。
  2. 双击 启动.bat（如果双击没反应，改用同目录的 start.bat）。如果 Windows 弹「已保护你的电脑」或杀毒软件提示，选择「更多信息 → 仍要运行」。
  3. 浏览器会自动打开一个页面，把抖音链接粘进去，点「开始解析」，等进度跑完就能看到文案。
第一次启动会慢一些（要加载模型，约 10–20 秒），之后会快很多。解析过程中会弹出一个浏览器窗口抓取视频，属于正常现象，不要关它。

三种使用方式

方式一：网页界面 推荐

双击 启动.bat，浏览器自动打开本地页面 http://127.0.0.1:8765。

  1. 在输入框里粘贴抖音分享链接（手机抖音「分享 → 复制链接」得到的那段）
  2. 点「开始解析」，页面会显示进度
  3. 完成后可直接「复制文案」，或点「打开输出文件夹」

适合：日常一条条解析，不想碰命令行的人。

方式二：控制台 进阶

双击 启动-控制台.bat，按提示粘贴链接后回车。

  1. 选择「1. 单条解析」或「2. 批量」
  2. 粘贴链接，回车
  3. 看完整过程日志；失败时日志会告诉你是哪一步出的问题

适合：批量解析、想排查问题、想看详细日志的人。

方式三：接进 AI 客户端 进阶

如果你已经在用 CC GUI / Claude Code / Cursor 这类 AI 客户端，可以把 skills\douyin-parse 这个技能目录复制到客户端的技能目录里，之后直接在对话框里发链接：

帮我解析这个链接 https://v.douyin.com/xxxx/

适合：已经在用 AI 客户端、希望「对话即解析」的人。

输出文件说明

每次解析会在解压目录的 output\ 下建一个文件夹，名字是「标题_日期」，里面有：

文件是什么
文案.txt纯正文，已加标点、已纠错，直接复制就能用
文案_分析版.md标题 + 元信息表 + 正文 +（可选）AI 可靠性分析
画面文字.md从视频画面里识别出的文字（字幕、图表、水印）
修订报告.md语音识别纠错记录（有改动时才生成）
info.json元数据：标题、作者、时长、原始转录等
audio.wav提取出来的音频（可删，不影响文案）

常见问题

现象处理办法
双击没反应 / 窗口一闪而过看 logs\ 里最新的日志；多半是路径里有特殊字符，换个短路径试试
杀毒软件报毒把整个文件夹加入信任区（这类工具会被误判，属正常）
浏览器打开是空白页端口被占用：关掉之前的窗口再启动；或重启电脑后再试
提示「无法获取音频」抖音改版或网络问题。先重试一次；仍失败请带日志联系售后
转录很慢10 分钟以上的视频会明显变慢。建议单条不超过 10 分钟，或改用「快速模式」
要不要联网抓视频必须联网；转录、OCR、纠错全部在本地完成
要不要买 AI不需要。默认不调用 AI，出来的是纯文案；想要「可靠性分析」可以填自己的 key（可选）
能装几台电脑解压即用，不限台数；但请勿转卖或公开传播
