抖音视频一键解析  ·  用法说明
================================

【最常用】
  解析一条视频：
      run_douyin.bat "https://v.douyin.com/xxxxxx/"
  把抖音分享出来的链接，原样粘在引号里即可。

  视频被误判成图文时，加 -v 强制按视频解析：
      run_douyin.bat "https://v.douyin.com/xxxxxx/" -v

  批量解析（links.txt 一行一个链接，空行和 # 开头跳过）：
      run_douyin.bat --batch "links.txt"

【跑之前可以先 set 的开关】
  换转录模型（长视频建议 small，速度快很多）：
      set DOUYIN_WHISPER_MODEL=small
  可选：small（快） / medium（中） / large-v3（准，慢）。不 set 默认 large-v3。

  切换 AI 供应商（标点恢复 + 可靠性分析）：
      set DOUYIN_AI_PROVIDER=deepseek
  可选：mimo / deepseek。不 set 默认 mimo，失败自动回落 deepseek。

  跳过画面文字提取（OCR）：
      set DISABLE_VIDEO_OCR=1

  改输出目录：
      set DOUYIN_OUTPUT_BASE=D:\某个目录

【结果在哪】
  每次跑完，结果文件夹在输出目录里，叫  {编号}_{标题}_{日期}：
      文案.txt          正文
      文案_分析版.md    正文 + AI 可靠性分析
      修订报告.md       ASR 修正记录（有修正时才生成）
      info.json         元数据
      audio.wav         提取的音频

  运行日志在输出目录下的 temp_logs 文件夹里。

【跑完看这行】
  最后一行是 ===EXITCODE=0=== 表示成功，非 0 表示失败，
  失败时打开 temp_logs 里最新的日志看原因。
